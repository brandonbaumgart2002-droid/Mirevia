# Theme overrides

Files here are edited copies of the store theme's own files (not ParaPatrol sections). Copy them back into the theme if the theme is ever re-downloaded.

- `custom-footer.liquid`: on the ParaPatrol template only (`template.suffix == 'parapatrol'`) the footer uses ParaPatrol newsletter copy ("Gentle tips for little tummies"), a white newsletter band, a navy footer and the ParaPatrol fonts. Every other page keeps the Mirevia footer settings unchanged. Search the file for `pp_footer`.
